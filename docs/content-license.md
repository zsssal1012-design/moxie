## 2. 内置内容部分（词库 / 诗文 / 题目）

内置数据分三类：

| 类别 | 版权状态 | 你可以 |
|---|---|---|
| 中国古代诗文（唐诗宋词文言文等） | 一般已进入**公版**（作者去世超过法定保护期） | 自由使用、修改、商用（仍建议核对具体篇目） |
| 现代文选段、教材专有文本 | **可能仍受版权保护**，教材汇编另有权利 | ❌ 不要用于商用/再分发；请替换为你自己整理的内容 |
| 英语单词表 | 单词本身不受版权保护；但**特定教材的单元编排、释义、例句、排版**可能受保护 | ⚠️ 使用"课标通用词汇 + 自编释义"，不要整册搬运教材词表 |

## 3. 因此本项目的立场

- 仓库默认**不授予内置教材类内容的再分发许可**
- 任何涉及教材原文的 PR，维护者有权要求改为"占位条目 + 用户自备词库"
- 商用/上架前，请先把内置词库切换为自己拥有权利的语料

## 4. 计划中的解法（欢迎认领）

- 把词库从 HTML 中剥离为 `data/*.json`，运行时按需下载
- 建立 `moxie-data` 独立仓库，社区共建"自编词库"，与代码仓库分离授权
- 提供词库导入器：用户在本地生成自己的词库文件，永远不需要把教材内容上传到公网仓库
