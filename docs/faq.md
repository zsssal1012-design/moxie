# 常见问题（家长 / 老师版）

**Q：一定要装 App 吗？**
不用。点开 https://zsssal1012-design.github.io/moxie/ 就能用，浏览器里和 App 一模一样。

**Q：要不要注册、要不要登录？**
都不要。没有账号系统，没有服务器，不收集任何信息。

**Q：断网能用吗？**
能。默写功能全部在本地跑。只有"在线朗读"和"短语翻译"这两个功能需要联网。

**Q：孩子的默写记录存在哪？会不会传给谁？**
只存在这台设备本地（浏览器 localStorage）。卸载或清除浏览器数据就没了，没有任何上传。

**Q：怎么把记录留档？**
目前可以用系统截图保存；「导出 PDF」与「错词本」已列为待开发功能（见 Issue #4 与功能建议区）。默写记录保存在本机，换设备需重新录入内容。

**Q：词库是我孩子教材的版本，能自己改吗？**
可以。应用内支持自行录入与编辑默写内容，改动只存在你自己设备上，不会上传到任何地方。
更便捷的批量导入（直接选 CSV / JSON 文件）已列为待开发功能，见 Issue #1，欢迎认领。

**Q：为什么强制横屏？**
针对平板大屏阅读优化，字距和答题区都按横屏排。手机上横过来用效果最佳。

**Q：装了旧版本，升级会不会丢记录？**
不会。Release 里的 APK 与旧版使用同一签名密钥，可直接覆盖安装。

**Q：这软件收费吗？能拿去给孩子所在班级用吗？**
免费，代码是 Apache-2.0，学校/机构可自由部署。唯一注意：教材原文与词表汇编的版权不属于本项目，见 docs/content-license.md。

**Q：我想要一个功能 / 发现一个错别字，怎么提？**
仓库首页点 Issues → New issue，用大白话描述就行。不会写也没关系，在家长群里说一声，我帮你录进来。

**Q：我不会编程，也能为开源做贡献吗？**
能。这个项目的多数贡献都是"数据"和"文字"：补一单元词表、挑一个错字、拍一张截图，都算。见 CONTRIBUTING.md。
